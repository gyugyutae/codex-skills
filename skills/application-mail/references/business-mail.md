# Professional document-submission email

Use concise, courteous business correspondence by default. Write Korean for domestic scholarship administration and English for international employers unless the recipient requests otherwise. Match terminology and subject requirements in the official notice.

## Structure

1. Subject: purpose/programme or job ID + applicant name. Examples: `[장학금명] 지원서류 제출 — 김규태`, `Application: Software Engineering Intern (Job ID) | GYUTAE KIM`. Use `Eligibility enquiry` for a question, not `Application` before an actual application.
2. Named recipient or team, brief identity and purpose. Avoid generic flattery and long personal histories.
3. State the exact documents and why supplied; short relevant fit paragraph only if helpful. Mention missing files clearly rather than saying the application is complete.
4. One specific action/request, such as reviewing an application or confirming an unresolved eligibility condition. Request receipt confirmation when meaningful, not on every routine inquiry.
5. Consistent signature: name, degree/university, intended reply address, relevant GitHub/portfolio. Add phone only when useful. Do not put bank/account numbers or other document secrets in the subject/body/filenames.

Plain or lightly formatted text; no decorative banners, emoji, excessive bold, unreadable tables or repeated salutations. Draft the attachment list using intended final filenames and reconcile it with actual uploaded files before calling the draft ready. Never say `attached` in a text-only compose action that has no uploaded files; show a pending-upload note outside the message, or revise the text until attachment is complete.

## File naming

Automatically clean confusing names (`최종진짜수정본(3).pdf`, download IDs, duplicate suffixes) into clear recipient-facing filenames. Preserve originals: create submission copies in a private working folder, or use the helper's `filename` override for the uploaded MIME attachment name. For browser uploads, use the renamed copies because file chips usually use local basenames. Confirm actual draft attachment names match the message.

- Overseas: `GYUTAE_KIM_CV.pdf`, `GYUTAE_KIM_Motivation_ASML.pdf`, `GYUTAE_KIM_Portfolio.pdf`, `GYUTAE_KIM_Transcript_2026-10-26.pdf`.
- Domestic: `김규태_장학금명_신청서.pdf`, `김규태_통장사본.pdf`, `김규태_재학증명서.pdf`.
- Follow a notice's mandatory naming convention first. Avoid account numbers, ID numbers, passwords and false issue dates. Use an issue date only after verifying the document; an arbitrary creation date is not a certificate's issue date.
- Preserve the real extension and content. Renaming `.hwp` to `.pdf` is not conversion. If conversion is needed, produce and inspect a real converted file. Reject filename collisions and ambiguous versions rather than overwriting originals.

## English example — only after actual attachment verification

Subject: Application: Software Engineering Intern (JOB-ID) | GYUTAE KIM

Dear Recruitment Team,

I am a software engineering undergraduate at Gyeongsang National University in South Korea. I am writing to apply for the Software Engineering Intern position (JOB-ID), following the submission instructions in your vacancy notice.

My interests include software testing and backend reliability. My undergraduate research on source-test traceability has given me experience examining analysis criteria and explaining their effect on results.

Please find my CV and relevant supporting documents attached:
- GYUTAE_KIM_CV.pdf
- GYUTAE_KIM_Portfolio.pdf

Thank you for considering my application. I would welcome the opportunity to discuss how my experience relates to the role.

Best regards,
GYUTAE KIM
Software Engineering Undergraduate | Gyeongsang National University
zn7034@gnu.ac.kr

Adapt facts, actual uploaded filenames and the recipient's accepted submission channel. This template does not authorize email applications to portal-only employers.
