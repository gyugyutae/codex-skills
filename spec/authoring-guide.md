# Short, executable skills

- Write description for selection: task, triggers, meaningful exclusions only if needed.
- Start with the deliverable; use a task-to-action table for multiple operations.
- Give direct actions or runnable commands; remove generic coaching and repeated rules.
- Keep the main path short. Link detailed procedures where needed.
- Put repeatable transformations and mechanical checks in scripts; keep judgment in instructions.
- Separate procedure from personal profiles, examples and one-time history.
- Preserve original-document constraints, scope and authorization when shortening.
- Remove unused template sections; do not impose a word quota or create empty resources.

Before delivery: validate metadata, run changed tools on realistic success and failure
cases, inspect real outputs, report unresolved requirements outside the output, and
keep UI metadata/local installation consistent. This template does not itself guarantee
quality or portability across runtimes.
