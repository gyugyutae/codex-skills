## Personal skill authoring preferences

When creating or updating a skill, read `~/.codex/skill-templates/authoring-guide.md`
and start from `~/.codex/skill-templates/SKILL.template.md` when available.
Use a short, task-oriented entrypoint with direct actions and runnable examples.
Link detailed procedures and personal facts from supporting files; do not duplicate them.
Omit unnecessary sections and preserve existing behavior, scope and authorization.
Validate metadata and changed tools against realistic success/failure cases.
These preferences apply only to skill authoring, not unrelated user outputs.
